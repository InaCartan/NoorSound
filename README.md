# NoorSound

NoorSound is a cross-platform audio app where users can upload their own audios, organize them in playlists, and listen to audios shared by other users.

> 🚧 **Work in progress:** this project is still under active development. Features may change, and some parts are not finished yet.

## Features

- Sign up and log in with an account
- Upload audios with a cover image
- Add playlists
- Browse audios, uploaded by other users
- Play audios
- Manage your library (view and delete your audios)

## Coming soon

- Search
- Viewing other users' profiles

## Built with

- .NET MAUI for the cross-platform app
- MVVM with CommunityToolkit.Mvvm
- Supabase for authentication, database and file storage
- .NET MAUI Community Toolkit (`MediaElement`) for audio features
